# Fonts

Download Lato font files and place them here:

1. Go to: https://fonts.google.com/specimen/Lato
2. Download the font family
3. Extract and copy these files here:
   - Lato-Regular.ttf
   - Lato-Bold.ttf

Or download directly from:
https://github.com/google/fonts/tree/main/ofl/lato

Required files:
- assets/fonts/Lato-Regular.ttf
- assets/fonts/Lato-Bold.ttf
